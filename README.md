# Suggestions

- If you are stuck for an extended period of time, take a deep rest or sleep and come back with a refreshed mind. There is no need to rush. 

- Don't forget to take notes after finding an answer or taking a progress as you will surely have to read them to track yours later.

- There will be times for you to look back to the previous questions to connect with the current process.

- There should be no embarrassment in seeking help and seeing others' walkthroughs to reverse-engineer the solution to get the idea and logic, but you have to understand the solution and should be able to implement it in the future if needed.
